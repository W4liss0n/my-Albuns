# Triage Labels

| Canonical role      | Label in this tracker | Meaning                                  |
| ------------------- | --------------------- | ---------------------------------------- |
| `needs-triage`      | `needs-triage`        | Maintainer must evaluate the issue       |
| `needs-info`        | `needs-info`          | Waiting for more information             |
| `ready-for-agent`   | `ready-for-agent`     | Fully specified and ready for an agent   |
| `ready-for-human`   | `ready-for-human`     | Requires human implementation or choice  |
| `wontfix`           | `wontfix`             | Will not be actioned                     |

Skills must use the label in the second column when recording a ticket's status.
